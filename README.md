# Харцызск — город с характером

## Назначение

Учебный многостраничный сайт о Харцызске для лабораторной работы №1 по HTML и CSS. Проект знакомит с историей, городской инфраструктурой и культурой города; отдельная страница рассказывает об авторе, ещё одна содержит форму обратной связи.

## Технологии

- HTML5 — семантическая разметка страниц и HTML-валидация формы;
- SCSS (Sass) — исходные стили сайта;
- CSS — скомпилированные стили, которые загружает браузер;
- npm — установка Sass и запуск сборки;
- Emmet — инструкции структуры страниц в `2.3.3 Дополнительное задание/Emmet-инструкции.md`.

## Страницы

- `index.html` — главная страница, фотогалерея и события;
- `history.html` — краткая история и таблица значимых событий;
- `infrastructure.html` — география, карта, районы и транспорт;
- `culture.html` — культурные учреждения, места и события;
- `about.html` — информация об авторе и диаграмма навыков;
- `contact.html` — форма обратной связи.

В `2.3.2 Усложненное задание/` находится отдельная CSS-иллюстрация персонажей «Южного парка» без изображений. В `2.3.3 Дополнительное задание/` хранятся Emmet-инструкции.

## Структура проекта

```text
lab1/
├── index.html, about.html, history.html
├── infrastructure.html, culture.html, contact.html
├── scss/
│   └── styles.scss          # исходные стили основного сайта
├── css/
│   └── styles.css           # собранные стили основного сайта
├── img/                     # фотографии и иллюстрация автора
├── assets/design/           # макет главной страницы
├── 2.3.2 Усложненное задание/
│   ├── index.html
│   ├── styles.scss
│   └── styles.css
├── 2.3.3 Дополнительное задание/
│   └── Emmet-инструкции.md
├── package.json
└── README.md
```

Каталог `node_modules/` появляется после установки зависимостей и не нужен в репозитории; он добавлен в `.gitignore`.

## Запуск локально

Нужны Node.js и npm. В PowerShell из корневой папки проекта выполните:

```powershell
npm ci
npm run build:all-css
py -m http.server 8000
```

Откройте <http://localhost:8000>. Если Python Launcher недоступен, можно открыть `index.html` напрямую; встроенная карта и веб-шрифты требуют подключения к интернету.

`npm run build:all-css` собирает `scss/styles.scss` в `css/styles.css`, а SCSS и CSS задания по «Южному парку» — в папке задания.
