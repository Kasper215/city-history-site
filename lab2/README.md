# Домтех

Адаптивный интернет-магазин бытовой техники с пятью страницами: главной, каталогом, карточкой товара, корзиной и оформлением заказа. Дополнительно подготовлен отдельный адаптивный шаблон письма. Структура и композиция страниц основаны на макетах PSD.

## Технологии

- HTML5, CSS3 и JavaScript
- Адаптивная сетка CSS Grid/Flexbox
- SVG-иллюстрации техники и сохранение корзины в браузере
- HTML5-валидация полей оформления заказа
- SEO-метаданные, Open Graph и карта сайта для публичных страниц

## Запуск

Откройте `index.html` или запустите локальный сервер из этой папки командой `py -m http.server 8000`, затем перейдите на `http://localhost:8000`.

Корзина работает в браузере. Отправка заказа и подписка на рассылку пока не подключены к серверной части.
